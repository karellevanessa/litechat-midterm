# ITENT 45 Midterm Prompt

## Brief

You are asked to replicate the core functionality of Litechat. Litechat is a web app that allows its users metered, _a la carte_ access to LLMs from various providers. The intent of the platform is to allow regular users (i.e., not power users) access to powerful AI models, which would normally require an upfront investment in a subscription that regular users are unwilling to pay for.

You can view the real Litechat app at: [https://litechat.ai](https://litechat.ai).

I (Joe) should have emailed you an **API key** that you can use to access a set of LLMs at [https://proxy.litechat.ai](https://proxy.litechat.ai).
